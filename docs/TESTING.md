## Что проверено автоматически

- Обмен Unicode, русским текстом и emoji между независимыми ключевыми парами; отдельными изолированными браузерными профилями.
- Полный интерфейсный цикл изображения и аудио: импорт с известными метаданными → приватная копия → шифрование → расшифровка в другом профиле → совпадение байтов → отображение PNG и проигрывание WAV. Во время цикла браузерные профили находились офлайн, новые сетевые ответы отсутствовали; статические Worker загружались из service worker.
- Аутентификация ключей, неверный получатель/отправитель, отражение собственного исходящего контейнера как входящего, повреждения заголовка/конверта/блоков, усечение, перестановка, повтор и подмена блоков, отсутствие/раннее появление финального тега, лишние данные, недопустимое дополнение. Проверены и корректно аутентифицированные, но структурно недопустимые потоки.
- Контейнер на максимально разрешённый файл 8 МиБ; случайность повторных операций; строгие типы, UTF-8, размеры, параметры резервных копий; группировка и сборка частей, пропуски, конфликты, смешение наборов и контрольные суммы.
- Восстановление зашифрованной локальной копии и скачанного файла, неверный пароль, отсутствие открытых ключей/имён/паролей в сохранённом шифротексте, сброс проверки при изменении ключа контакта.
- Реальная браузерная повторная кодировка PNG и JPEG с известными EXIF, GPS, XMP и комментариями; удаление этих маркеров, сохранение ожидаемых пикселей PNG. Декодирование и кодировка WAV с LIST/INFO, именем и исполнителем; отсутствие исходных тегов и корректный PCM.
- Запись через AudioWorklet с **синтетическим микрофоном Chrome**: формирование WAV, остановка всех дорожек, отмена без выдачи результата. Физический микрофон не проверен.
- Отказ для SVG/HTML, неверного MIME, неподдерживаемого HEIC, анимации, повреждённых заголовков, чрезмерных размеров/пикселей/длительности. Ограничения MP3 и Ogg проверены структурными тестами, а не всеми существующими вариантами файлов.
- Текст с HTML и внешним URL остаётся текстом; код не выполняется и внешняя картинка не загружается.
- Пустые localStorage/sessionStorage/IndexedDB до явного сохранения; только фиксированные статические URL в Cache Storage; отсутствие ошибок консоли и запросов во время текстового обмена. Дополнительные статические проверки исключают явные сетевые API, логирование и динамические HTML-вставки в прикладных модулях.
- Офлайн-перезапуск с размещением в `/QuietChat/`; проверка полного кэша, отказ при повреждении/недостающем ресурсе, восстановление только той же версии; отсутствие принудительной активации обновлений. Первый сеанс допускает разблокировку лишь после контроля страницы проверенной версией worker.
- Очистка интерфейса и ключей при блокировке; программно вызванный уход в фон; таймер 5 минут через виртуальные часы Playwright.
- Адаптивная ширина 390 px без горизонтального переполнения страницы. Просмотрены скриншоты пустого интерфейса на ПК и узком экране.

## Что не выполнялось

- Реальные iPhone/Safari, Android/Chrome, установленная PWA на телефоне, физический микрофон, системный буфер обмена, системный выбор/сохранение файлов и фактические снимки переключателя приложений.
- Firefox и Safari на ПК; обмен изображениями и WAV между разными браузерными движками; все варианты WebP, MP3, Opus, AAC и EXIF-ориентации.
- Публикация в GitHub пользователя и реальный прогон GitHub Actions: в рабочей папке не был задан репозиторий/remote. Workflow и инструкция готовы, локальное размещение в подпапке проверено.
- Реальное обновление опубликованной PWA при двух открытых вкладках. Поведение обработчиков проверено изолированными тестами; ручная матрица в README остаётся обязательной.
- Нагрузочное профилирование Argon2id и декодеров на слабом телефоне, независимый криптографический аудит, доказательство отсутствия всех сторонних каналов.

Успешные тесты описывают конкретные проверенные сценарии. Они не гарантируют отсутствие неизвестных ошибок, уязвимостей браузера или компрометации устройства.
